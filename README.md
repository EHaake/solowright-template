# Solowright project template — archived

Solowright projects are no longer started from this template. The
skill now scaffolds a new project itself: create an empty repository,
open Claude Code in it, and say "Start a new Solowright project." The
first session writes the project's skeleton from the skill's own
templates, so every project starts from the current ones.

Everything that lived here has moved to the skill repo,
**[EHaake/solowright](https://github.com/EHaake/solowright)**: the
document templates are in `assets/`, the human guide is
`How-To-Use.md`, and the reasoning for retiring this repo — a copy of
the templates drifted from the originals within weeks — is in
`references/design-record.md`.

This repository is archived and read-only.
